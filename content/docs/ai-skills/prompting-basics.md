---
title: Prompting basics
description: Write focused instructions that help the AI assistant provide useful educational support.
---

A prompt is the question or instruction you send to the assistant. Strong prompts explain the task, relevant context, preferred output, and any important limits.

## Use four prompt ingredients

1. **Task:** What should the assistant do?
2. **Context:** Which course, topic, document, or audience matters?
3. **Format:** Should the response be a checklist, explanation, table, or quiz?
4. **Limits:** How long, difficult, or detailed should it be?

```text
Explain photosynthesis for a first-year biology student. Use one everyday analogy, then provide five self-check questions without answers.
```

## Add context deliberately

Mention the course and learning objective. When working from uploaded material, identify the relevant lecture, document, or section.

## Ask for a suitable format

Choose a format that matches the work:

- A numbered process for procedures.
- A comparison table for related concepts.
- Flashcards for retrieval practice.
- Questions without immediate answers for self-testing.
- A short worked example for calculations.

## Improve a weak response

Do not repeat the same broad request. Tell the assistant what needs to change: simpler language, additional evidence, a different example, fewer topics, or a clearer structure.
