---
title: Choose source context
description: Help the assistant use the correct course, document, and conversation context.
---

AI answers improve when the assistant knows which information should guide the response. In MFU AI, that context may come from a selected course, uploaded documents, and the messages already exchanged in the conversation.

## Select the correct course

Confirm the course before asking a course-specific question. Two courses may use the same term differently or apply different assessment rules.

## Name the source

Refer to the document or section explicitly when it matters.

```text
Using the Week 3 lecture slides, compare supervised and unsupervised learning. Do not add methods that are absent from the slides.
```

## Keep conversation context clean

Follow-up questions use earlier messages as context. Start a new conversation when you change to an unrelated course or topic, or when the current thread has become confusing.

## Recognize missing evidence

If the uploaded material does not contain the answer, the assistant should say so. Ask for the source used and verify the response against the original file.

> Selecting a document does not guarantee perfect retrieval. Important claims still require human review.
