---
title: Troubleshooting
description: Resolve common problems with access, browsers, course content, uploads, and AI responses.
---

## I cannot sign in

1. Confirm that you are using your approved MFU email address.
2. Check for accidental spaces and keyboard capitalization.
3. Try the [password reset page](/forgot-password).
4. Open the site in a private browser window to rule out stale session data.
5. If the problem remains, contact support with the time of the attempt and the error message.

Never send your password to support.

## The page looks incomplete

Refresh the page and update the browser to its latest stable version. Temporarily disable browser extensions that change page content or block scripts. If possible, compare the result in another supported browser.

## A course or document is missing

Confirm that the correct course is selected and that your account has access. Students should ask the teacher to verify enrollment and document availability. Teachers should check that the file was uploaded to the intended course and finished processing.

## A document upload failed

Check that the file format is supported, the file is not damaged, and the network connection is stable. Rename the file with a simple descriptive name and retry once. Avoid repeatedly uploading the same file while processing is still in progress.

## The AI answer is unrelated or incorrect

- Ask a narrower question.
- Name the course, topic, or document.
- Use terminology that appears in the source.
- Start a new conversation if earlier messages introduced unrelated context.
- Report repeated errors to the teacher or project team.

## Information to include in a support request

Provide the page URL, your role, the browser name, the approximate time, the steps that led to the problem, and the visible error message. Include a screenshot only after checking that it contains no passwords, private conversations, grades, or personal information.
