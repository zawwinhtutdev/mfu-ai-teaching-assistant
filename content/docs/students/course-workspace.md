Open **My Courses** in the student portal and select a course. Check the course code and title before using any AI activity.

![Student course announcements workspace](/docs/student-course.png)

## Announcements

The **Announcements** tab is the course feed. It can contain teaching updates, assignment notices, links, grouped information, and attached files.

1. Read the newest item and its date.
2. Open any attached file in a new tab.
3. Confirm deadlines and assessment instructions against the official course source.
4. Complete any survey shown below the feed when your teacher requests it.

If the feed is empty, the course has no announcements available to your account yet.

## AI Assistant

The **AI Assistant** tab contains four course-aware tools:

![Course AI assistant tools](/docs/course-ai-tools.png)

- **AI Chat** for explanations and follow-up questions.
- **Flashcards** for question-and-answer review.
- **Quizzes** for scored practice questions.
- **Planner** for manual or AI-generated study tasks.

The selected course supplies the assistant’s course ID, materials, and teacher-defined chatbot settings. Keep unrelated questions in a general [AI Chat](/chat) conversation.

## Ask a course question

```text
Using this course’s Week 3 material, explain the difference between authentication and authorization. End with one checking question.
```

If the assistant cannot find the information, do not assume the missing answer is false. The required material may not have been uploaded or indexed.

## Use course practice activities

Open [Flashcards](/docs/students/flashcards) for rapid recall, [Quizzes](/docs/students/quizzes) to check understanding, or [Study Planner](/docs/students/study-planner) to schedule another review cycle.

## Course access problems

- If the course does not appear in **My Courses**, confirm that you enrolled with the correct account.
- If only one tool is empty, the teacher may not have created that activity.
- If all course data fails to load, refresh once and follow [Troubleshooting](/docs/support/troubleshooting).
