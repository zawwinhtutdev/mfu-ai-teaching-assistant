---
title: Announcements and FAQs
description: Publish course updates with attachments and maintain trusted answers that the course assistant can prioritize.
---

Announcements communicate time-sensitive course information. FAQs provide stable, reusable answers that the course AI assistant can prioritize when students ask common questions.

## Create an announcement

1. Open the course from **Teacher Portal** → **My Courses**.
2. Stay on the **Announcements** area.
3. Choose the action to create an announcement.
4. Write a concise title and message.
5. Attach a file only when students need it.
6. Review links, dates, and course details before publishing.

Put the required action near the beginning. For deadlines, include the date, time, timezone, and authoritative assessment location.

## Edit or delete an announcement

Open the three-dot menu on an announcement. Use **Edit** to correct the message and **Delete** only when the item should no longer be available.

Deleting an announcement is a destructive action. For a changed deadline, editing the post and clearly noting the correction may give students a better record.

## Add a course FAQ

1. Open the course’s **AI Assistant** area.
2. Choose **FAQs**.
3. Enter the student question using likely wording.
4. Enter the approved answer.
5. Select **Add FAQ**.

The assistant prioritizes these entries when answering students. Use FAQs for stable facts such as office hours, late-work rules, assessment weights, or where to find a resource.

## Write reliable FAQ answers

- Keep one policy or topic per entry.
- Use the same terminology as the syllabus.
- Include an effective date when rules can change.
- Point to the authoritative course source.
- Avoid private student-specific information.

```text
Question: Where is the grading breakdown?
Answer: See the Assessment section of the current course syllabus in Materials. If the syllabus and an announcement differ, contact the instructor before relying on either value.
```

## Maintain the FAQ set

Review FAQs when a syllabus, schedule, or policy changes. Delete obsolete entries and add a replacement immediately so the assistant does not prioritize outdated guidance.

> An FAQ improves consistency but does not replace the official syllabus, assessment brief, or direct instructor decision.
