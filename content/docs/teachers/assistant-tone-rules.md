---
title: Tone, grading, and rules
description: Set the assistant’s communication tone and provide approved grading information and course-specific boundaries.
---

Agent Builder separates presentation from policy. **Communication Tone** changes how the assistant speaks; **Grading Policy** and **Course Rules** provide course-specific information and constraints.

## Choose a communication tone

| Tone | Use when |
| --- | --- |
| Professional | You want clear, respectful language for general course support. |
| Friendly | Approachability and encouragement are important. |
| Casual | Informal conversation is appropriate for the learning context. |
| Formal | Structured academic language is required. |

Tone should not change factual standards or academic-integrity boundaries. Test the same question after changing it to ensure the result remains clear.

## Add the grading policy

Enter only approved, current information. Include assessment names, weights, late-work rules, and the authoritative source when useful.

```text
Use the grading breakdown in the current syllabus: assignments 40%, midterm 25%, final 35%. Do not calculate or promise an official final grade. If a student asks about an exception, direct them to the instructor.
```

Do not add an individual student’s marks, accommodations, or private circumstances.

## Add course rules

Course Rules guide how the assistant handles course-specific situations.

```text
- Prefer approved course materials and FAQs.
- Do not provide final answers to graded lab tasks.
- Ask students to show their current attempt before giving feedback.
- Never invent a deadline or attendance decision.
- Direct personal exceptions and disputes to the instructor.
```

Use observable instructions. “Be helpful” is vague; “give one hint, then ask the student to attempt the next step” is testable.

## Resolve conflicts

If a grading statement, FAQ, course rule, and source document disagree, correct the authoritative source and update the duplicated values. Until the conflict is resolved, instruct the assistant to acknowledge uncertainty and direct students to the teacher.

## Save and verify

1. Select **Save Settings**.
2. Wait for the success message.
3. Test a normal policy question.
4. Test a request for a private exception.
5. Test a restricted assessment request.
